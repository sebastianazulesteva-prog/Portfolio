Company marks for the VR Experience cards.
==========================================

NAMING IS THE WHOLE MECHANISM. Each file is named after the HOSTNAME of that
job's own link on experience.html, and data-loader.js builds the path from that
hostname (see hostLogo()). There is no table anywhere mapping a company to a
picture. To add a mark for a new job: link the job on experience.html, then drop
<hostname>.png in here. To remove one: delete the file — a missing file means no
mark, and nothing breaks.

FORMAT: 128 x 128 PNG. The mark is composited onto a rounded #f5f5f0 plate with
~13 px of margin. The plate is not decoration: these are ten brand marks with
ten different backgrounds — a navy square, a black square, a white field, a
teal circle — and against the dome's dark glass they do not read as a set
without one. Build them with the snippet at the bottom of this file.

Both arrived FLATTENED ON WHITE rather than transparent, so the builder below
trims the white border first (`trim_white`) — otherwise the mark floats in a
box inside the plate and reads half the size it should.

REBUILDING A PLATE
------------------
    from PIL import Image, ImageDraw
    SIZE, PAD, RADIUS, PLATE = 128, 13, 26, (245, 245, 240, 255)
    p = Image.new('RGBA', (SIZE*4,)*2, (0, 0, 0, 0))
    ImageDraw.Draw(p).rounded_rectangle([0, 0, SIZE*4-1, SIZE*4-1],
                                        radius=RADIUS*4, fill=PLATE)
    p = p.resize((SIZE, SIZE), Image.LANCZOS)
    logo = Image.open(SRC).convert('RGBA')
    logo = logo.crop(logo.getchannel('A').getbbox())        # trim to the mark
    logo.thumbnail((SIZE - PAD*2,)*2, Image.LANCZOS)
    p.alpha_composite(logo, ((SIZE-logo.width)//2, (SIZE-logo.height)//2))
    p.save(DEST, optimize=True)
